EVERYTHING IT CAN DO

Features

CONTENT

Choose what is on the label

The product name is always printed; the sales price, internal reference and barcode can each be switched on or off. Prices are shown in the product’s currency.

TEXT

Text size and an extra line

Small, medium or large text, and one line of your own on every label (up to 40 characters) — your shop name, “Made in …” or a short note.

BARCODES

The right barcode, automatically

EAN-13 for 13-digit barcodes and Code 128 for everything else, chosen from the product’s barcode with no settings. Products without a barcode still get a label.

QUANTITIES

Any number per product

Set how many labels each product needs and see the total before printing. Add or remove products in the same window; product variants each get their own line.

INSTALLATION

Nothing to set up

Product Label Builder depends only on Odoo’s Products app and prints with Odoo’s own PDF reports. There are no Python libraries to install and no settings to fill in.

Tip: in the print dialog of your PDF viewer choose Actual size (100%) so the labels come out in their exact size.

FIRST STEPS

  1. Install Product Label Builder from Apps.
  2. Open Product Labels → Print Labels.
  3. Tick the products and click Print Labels.
  4. Choose the layout and options, set the quantities, click Print.
  5. From any product list or form: Action → Label Builder (PDF).
